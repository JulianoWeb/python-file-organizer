# 📁 Organizador de Arquivos

Um organizador de arquivos desenvolvido em Python que separa automaticamente arquivos em diferentes categorias com base em suas extensões.

## 🚀 Funcionalidades

- Organização automática de arquivos
- Separação por categorias
- Criação automática das pastas
- Suporte para imagens, vídeos, documentos, músicas e código
- Arquivos desconhecidos são enviados para `Outros`
- Interface para escolher a pasta que será organizada
